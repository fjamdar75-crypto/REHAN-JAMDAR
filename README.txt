REHAN JAMDAR - Android App Project

This is an Android Studio source project, NOT a compiled APK.
1. Install Android Studio on PC.
2. Open this folder as a project.
3. Let Gradle sync (requires internet).
4. Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Find app-debug.apk under app/build/outputs/apk/debug/ and send it to phone.

Includes: REHAN JAMDAR icon, WhatsApp button to +91 9130136952, Hindi note, embedded https://cricketpridiction.netlify.app/ website.
Requires internet to load the website. The website is controlled separately and may be offline.
